# 素材与第三方说明

> 本整合版（1.0.0）叠加工作台黑金主题（`ui.skin=workshop`，配合 `dsh-theme-sandrone`），皮肤可在控制台切回 `aurora`（深蓝紫）；素材授权边界与下列各条一致。

这个仓库里的**代码**是 MIT（见 `LICENSE`）。**素材**不是，它们各有各的来源与限制，分发前请逐条看清楚。

## 角色与美术

- 「桑多涅」及其形象、《原神》相关素材版权归 **米哈游 / HoYoverse** 所有。
- `assets/figure.png`、`assets/cine.jpg` 取自官方角色卡与官方 4K 动态壁纸，仅作个人桌面美化使用，**不构成任何授权**。
- `icon.svg` 是照着角色特征手绘的原创 SVG（银褐发、金边帽饰、齿轮背饰），不含官方图形。

## 语音

- `assets/voice/*.m4a` 是用 **GPT-SoVITS** 微调的音色合成的，训练语料取自《原神》角色语音（CV：洪海天）。
- 声音的**表演权属于配音演员本人**。这份音色只用于个人、非商业的桌面助手；不要用它发布公开内容、接商单，或做任何可能让人误以为是官方或演员本人的表达。
- 若要公开分享，建议在简介里写明「音色由个人自训模型合成，非官方、非本人」。

## 字体

- 面板与开屏只用了系统字体（`Microsoft YaHei` / 宋体回退），没有内嵌字体文件。

## 免责

这份插件会：调用你配置的默认模型（消耗 token）、在本机拉起一个 python 语音服务（占用显存/内存）、把对话记录存在浏览器 localStorage。它**不会**替用户执行命令、读写文件或联网上传任何内容——人格提示里也写死了这一点。
