# 录屏分镜 · 实操演示片

目标：**4 分钟以内**，让人看完知道「这东西能干什么、在我机器上能不能跑、我要怎么装」。

原则：前面 15 秒必须是最漂亮的一帧，不要从桌面开始、不要从「大家好」开始。

---

## 一、录制前清单（10 分钟准备，省 1 小时返工）

**画面**

- [ ] 分辨率 1920×1080（有 2K 屏就录 2560×1440），60fps
- [ ] 任务栏设为自动隐藏；关掉桌面图标（或换一张干净的深色壁纸）
- [ ] 只留 DSH 一个窗口，铺满但**留一点边**（B 站播放器会裁边）
- [ ] 系统通知全关（Windows 专注助手 / 微信 / QQ）
- [ ] 输入法候选框挪到不挡字的位置，或全程用粘贴

**声音**

- [ ] OBS 音频源用「桌面音频 / 应用程序音频采集」，不要用麦克风录音箱
- [ ] 录前先播一句台词，确认波形峰值在 −12 dB 到 −6 dB 之间
- [ ] 关掉所有会响的东西（提示音、音乐播放器）

**内容准备**

- [ ] 先跟她说一句话**预热引擎**（第一次 5–20 秒启动，绝对不要录进去）
- [ ] 准备好要打的句子，复制到剪贴板，录制时 Ctrl+V
- [ ] 对话历史清空，或只留一段你觉得好看的
- [ ] 确认 `/sandrone/setup` 里 Lite 那一条是绿灯

**录制习惯**

- [ ] 分成 6–8 段录，每段 20–60 秒，不要一口气录完
- [ ] 每段开头停 2 秒再动鼠标（剪辑要有余量）
- [ ] 鼠标移动放慢，点击前停 0.3–0.4 秒
- [ ] 每段结束停 1 秒再停录

## 三、录完给我什么

- 按镜号命名：`01-开屏.mp4`、`02-问候.mp4`……
- 原始文件直接给（不要先压缩/转码）
- 如果某段重录过，用 `01-开屏-take2.mp4`，我自己挑
- 顺手截几张静帧（`/preview` 那种清晰度）当封面备选

我拿到的处理：按镜号对齐切点 → 统一音量（旁白/原声分流）→ 章节条 + 字幕 → 片头 3 秒标题卡 → 片尾仓库地址。

## 四、几个容易翻车的点

1. **第一次说话一定预热**。引擎冷启动 5–20 秒，录进去就是事故。
2. **别用麦克风录系统声**，会糊。用 OBS 的桌面音频源。
3. **别在开屏时动鼠标**，开屏有镜头运动，鼠标一点就出戏。
4. **对话别问太长的问题**。她一轮只念前两句（58 字），问太复杂会出现「有字没声」，看起来像坏了。
5. **控制台改完要刷新或等 1 秒**再回面板，配置是异步生效的。
6. **别录调试接口的原始 JSON 太久**，观众看不懂，第 8 镜给 10 秒就够。
