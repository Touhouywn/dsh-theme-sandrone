# 把桑多涅接进 DSH：一个「会说话的角色插件」是怎么做出来的

> 面向视频分享的流程总结 + 可优化点清单
> 项目位置：`sandrone-fairy/`（DSH 插件，host + client 双半）

---

## 一、一句话说清做了什么

在 DeepSeek Harness 的 Web 界面里，加了一个**常驻的角色 AI**：

- **开屏**：一段电影化的镜头推进（原作画面 → 两人相拥于镜水 → 她的立绘浮现），配她的原声问候；
- **常驻**：右下角悬浮立绘，可拖拽，点击展开对话面板；
- **说话**：文字逐句出现，语音**同一刻**跟上，用的是她自己训练出来的音色；
- **氛围**：整层主题 token 覆盖成深蓝 + 紫，外加四角极光。

规模：`client.js` 90KB、`index.js` 22KB、立绘 1MB、14 条预烘语音 801KB。
模型：GPT-SoVITS v2ProPlus 微调权重（e1，165MB），参考音 `line4.wav`。

---

## 二、架构：三条路由 + 两个槽位 + 一层主题

```
浏览器（DSH Web）
├─ shell.overlay 槽位
│   ├─ 开屏：cine.jpg（原作帧）+ 镜头动画 + 立绘浮现 + 欢迎语
│   └─ 悬浮：figure.png（完整立绘，1:1 容器）+ 对话面板
│
└─ fetch（同源）
    ├─ POST /sandrone/chat   → NDJSON 流式文本（LLM，人格 prompt 内嵌）
    ├─ POST /sandrone/tts    → audio/wav（她的音色，逐句合成）
    └─ GET  /sandrone/asset/* → 静态素材（图、语音包，带白名单）
```

- **host 半**（`index.js`）：只做三件事——调 LLM、调 TTS、发文件。不碰 UI。
- **client 半**（`client.js`）：`window.__ModuleLoader__.load({ id, factory })`，`inject: ['slots']`，注册 `shell.overlay`（order 60），用错误边界兜住渲染。
- **主题**：`ctx.get('theme').overrideTokens(...)` 覆盖 14 个 token（深蓝/紫），极光用独立 DOM 层 + `mix-blend-mode: screen`。

## 三、走过来的关键转折（视频的戏剧点都在这里）

| # | 遇到的问题 | 真正的原因 | 结论 |
|---|---|---|---|
| 1 | 插件装上了但 `/chat` 只回一个 `done` | ①消息形状必须是 `{role, content:[{type:'text',text}]}`；②流式 chunk 的判别字段是 **`type`** 不是 `kind` | 两个都改对，对话才通 |
| 2 | 推理模型的「心里话」漏进了回复 | `blockType:'reasoning'` 的 text-delta 也被当正文转发 | reasoning 增量必须丢弃 |
| 3 | 改了宿主代码，行为不变 | ESM 模块被进程缓存；重复 `install_bundle` 只回 `already-installed` | 正确姿势：`set_plugin` 关→开（entryId 是 `include:sandrone-fairy`） |
| 4 | 立绘「少了一块」反复出现 | 容器写死像素 + 窗口一窄就裁；下渐隐 mask 又把脚吃掉 | 全部改 `var(--sdf-w/--sdf-h)` + `object-fit: contain` + 去掉 mask |
| 5 | 面板顶部跑到屏幕外 | `.sdf-panel` 里 `height` 被**重复声明**，后一条覆盖前一条 | 删掉死声明（纯 CSS 事故） |
| 6 | 「截图渲染完成」其实是旧图 | 预览脚本正则不匹配 CRLF 报错，我又把 stderr 吞了，Chrome 找不到 HTML 就不覆盖旧 png | 纪律：不吞 stderr、截图前先删旧图、比对 sha256 |
| 7 | 声音不像她 | Edge 神经语音只是「中文女声」 | 换成本地零样本/微调模型 |
| 8 | 从原画抠人物总是带白边 | 官方卡的**标题与台词直接压在人物身上**，物理上无法干净分割 | 放弃抠图，用「自带 alpha 的官方立绘」 |
| 9 | 训练到第 4 epoch 崩了，权重没存下来 | `my_save` 的目标目录不存在 → `WinError 3` | 两处 `my_save` 加 `os.makedirs(exist_ok=True)` |

**最值钱的一条经验**：第 6 条。如果我当时不吞 stderr、不比对文件哈希，后面所有「看起来改好了」的判断都是假的。

## 四、语音：换了三代，账要算清楚

| 方案 | 首字延迟 | 像不像她 | 代价 |
|---|---|---|---|
| Edge 神经语音（晓晓） | ~2.4s | ✗ 只是「好听的中文女声」 | 零成本，但你一听就出戏 |
| CosyVoice2 零样本克隆 | 3.8s（4GB 显存，RTF 4.3） | ◐ 有味道但不稳 | 显存吃满、要调 `n_timesteps` |
| **GPT-SoVITS 自训（e1）** | **~3.2s**（热态）/ 27ms（缓存命中） | ✓ 你自己说「可以用」 | 128 段语料、6 个 epoch、每 epoch 5.8 分钟 |

训练侧的几个数字（视频里很好用）：

- 语料：`白露` 视频 → 128 段 / 328.5 秒（旧版只有 71 段 / 179 秒）；
- 每 epoch **128 步 / 约 5.8 分钟**，6 个 epoch 出 6 个候选；
- 你盲听选型：**e1 人味最重**，e6 也不错，e3「纯机器感太重」；
- 语速 0.95、参考音 `line4`（能量最足的那条）、`prompt_text` 留空（靠说话人向量）。

## 五、如果要拍成视频，建议这样切

**4 分钟版（推荐）**

| 时间 | 画面 | 说什么 |
|---|---|---|
| 0:00–0:25 | 开屏镜头推进 → 立绘浮现 → 她说「……哼，回来了」 | 先给结果，不要先讲技术 |
| 0:25–0:55 | 点开面板，问一句，文字与语音同时出 | 「注意：字到哪，声音就到哪」 |
| 0:55–1:40 | 三条路由的示意图 + 一句「插件只做三件事」 | 架构不贪多，讲清 host/client 分工 |
| 1:40–2:30 | 三代语音的对比试听（放同一句） | 这是最有说服力的段落，别剪短 |
| 2:30–3:20 | 三个「事故现场」：already-installed / 重复 height / 旧截图 | 分享的价值在坑里，不在成果 |
| 3:20–4:00 | 现在的延迟表 + 下一步（流式 0.4s） | 留钩子 |

**拍摄前要做的三件事**

1. **彩排模式**：加一个 URL 参数或按钮，让开屏可以随时重放（现在要刷新页面）；
2. **固定输入**：演示用的问题写死 2–3 条，避免临场 LLM 输出太长把节奏拖垮；
3. **预热**：录制前先跑一次 `/sandrone/tts`（模型加载 14–16s）并命中缓存，画面里就只剩 27ms。

## 六、还能优化的地方（按性价比排序）

| 优先级 | 优化 | 现状 → 目标 | 说明 |
|---|---|---|---|
| ★★★ | **流式播放** | 首字 3.2s → **0.4s**（实测 `streaming_mode=3` 首字节 363ms） | 宿主透传 PCM，客户端 Web Audio 抖动缓冲；代价是音质略降（2 档可折中） |
| ★★★ | 演示/彩排开关 | 无 → 一键重放开屏 + 固定问答 | 录视频刚需，改动很小 |
| ★★☆ | 首句抢跑 | 首句要等整句合成完 | 把第一段切得更短（≤8 字）+ 缓存常用开场 |
| ★★☆ | 常驻服务托管 | GS 服务偶发随父进程退出 → 502 | 用 `detached` + 心跳自愈（已部分实现，需加日志） |
| ★☆☆ | 音色切换 | 只有 e1 | 面板里做成 e1/e6 可切换（权重已就绪，165MB×6） |
| ★☆☆ | 打包精简 | 立绘 1MB、语料 165MB×6 在仓库里 | 发版时只带 e1 + 立绘，训练产物和语料单独放 |

## 七、可复用的「坑清单」（给看视频的人）

1. **DSH 插件重载**：改 host 半 → `set_plugin` 关→开；改 client 半 → 刷新页面。
2. **流式 chunk**：判别字段 `type`；`reasoning` 增量别当正文。
3. **CSS 事故**：同一个属性写两遍，后写的那条会静默赢，`min()`/`calc()` 也不会报错。
4. **截图验证**：不吞 stderr、先删旧图、比 sha256——否则你在看昨天的图。
5. **Windows 编码**：PowerShell 往返 UTF-8 中文会变 GBK 乱码；用 `encoding='utf-8'` 直接读写。
6. **ffmpeg loudnorm**：会把采样率抬到 192k，mp3 封装装不下 → 必须显式 `-ar 44100`，否则静默失败。
7. **GPT-SoVITS prep**：必须在仓库根跑、`PYTHONPATH` 要含 `pretrained_models`、ffmpeg 要在 PATH 里，否则 hubert 阶段会产出 0 个文件。
8. **`my_save` 的目录**：训练保存前 `makedirs`，否则一整轮 epoch 白跑。
